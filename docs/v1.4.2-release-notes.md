# Corner Media Player v1.4.2

A small KDE Plasma 6 visual bug fix, distributed alongside the corresponding Windows package.

## Fixed
- **KDE Plasma 6:** the volume slider now uses the selected app theme for its background track, filled portion, and handle, instead of inheriting KDE's system-wide teal/green accent color. All five presets, including Burgundy Rose and Emerald Forest, recolor the slider immediately when switching themes.
- Playback volume still controls only the currently selected player via MPRIS. No changes to volume values or playback behavior.

## Unchanged
- **Windows:** v1.4.2 carries the same functional playback features as v1.4.1, with an updated package and version for paired releases.
- The Plasma plugin ID remains `org.mohannad.spotify.cornerplayer`, and the Windows installed file/ownership marker remain unchanged, so updating does not create a duplicate installation or erase preferences.
- MIT license is included in both archives.

## Packages
- `Corner-Media-Player-v1.4.2-Windows.zip`
- `Corner-Media-Player-v1.4.2-Plasma6.zip`

## Install
**Windows:** download and extract the Windows ZIP; run `Install.bat`. An existing owned installation is backed up and replaced in place.

**KDE Plasma 6:** extract the Linux ZIP, enter `Corner-Media-Player-Plasma6`, and run `python3 install.py --check && python3 install.py`. If the running panel shows an old version after the update, reload it using `systemctl --user restart plasma-plasmashell.service`. Existing theme/source preferences remain saved.

The previous v1.4.1 release is preserved for rollback. The project is unofficial and not affiliated with Spotify, Spotifast, or KDE.

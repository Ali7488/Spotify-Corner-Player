# Corner Media Player v1.5.1 — Linux compact UI fix

**Linux KDE Plasma 6 only.** The Windows stable release remains **v1.5.0**, unchanged.

## What changed

- **Compact means compact:** only the current track title, Previous / Play-Pause / Next buttons, and a small **Expand** icon. No record, album artwork, artist, seek bar, volume, header menus, source/theme actions, footer links, notices or other utility buttons.
- **Popup geometry shrinks:** preferred width `276` and height `104` in compact mode, versus `432 × 500` expanded (actual on-screen size depends on Plasma/dpi/panel constraints).
- **Expanded utility actions use 28px vector icons** instead of text: compact, pin/unpin, repeat/repeat-one, shuffle and Artwork/Vinyl; source and theme buttons also shrink.
- **Tooltips remain on hover** (450 ms delay). The tooltip describes the *action*, while accessible names preserve keyboard and screen-reader context.
- The artwork safety behavior from 1.5.0 remains: optional unmodified stationary square cover or original animated record that contains no cover art.
- All existing themes, auto-detection of Spotify/Spotifast MPRIS sessions, media controls, widget identity, stored preferences and installation backups remain intact.

## Upgrade

Download `Corner-Media-Player-v1.5.1-Plasma6.zip`, extract the archive and from the `Corner-Media-Player-Plasma6` folder run:

```bash
python3 install.py --check
python3 install.py
systemctl --user restart plasma-plasmashell.service
```

Per-user installation; no sudo. Existing widget settings are preserved. Use the icon in compact mode to expand the popup again.

## Windows users

There is **no v1.5.1 Windows archive** because no Windows code changed. Continue using [Windows v1.5.0](https://github.com/Ali7488/Spotify-Corner-Player/releases/tag/1.5.0).

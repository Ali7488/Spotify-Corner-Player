# Spotify Corner Player v1.4.0 RC1

**Prerelease / test candidate** for Windows and KDE Plasma 6. Stable v1.3.0 remains available. These packages must be tested on actual Windows and Plasma 6 desktops before declaring v1.4.0 stable.

## New in v1.4

### Windows
- Toggle compact/expanded popup from the header. The choice persists in `%LOCALAPPDATA%\SpotifyCornerPlayer\layout.txt`.
- Seek through a track by clicking or dragging the themed progress slider when the Spotify Windows media session reports seeking is supported. Otherwise the control is disabled.
- Repeat Off → All → One where Spotify exposes repeat controls through Windows media sessions; disables itself otherwise.
- **No pin/unpin control or pinning behavior in Windows v1.4**, by design.
- Legacy upgrade preflight and backup. Automatically recognizes the same signed ownership marker and startup location used by manually installed v1.2.4, as well as later owned versions. Stops only the existing Corner Player instance, backs up previous source and shortcut, and updates in place. Preserves themes and logs; restores the old app if new startup fails.

### KDE Plasma 6
- Toggle compact/expanded popup with saved Plasma KConfig setting.
- **Linux-only Pin open / Unpin** using native KDE popup focus behavior.
- Repeat Off → All → One using optional MPRIS LoopStatus where supported.
- Selected player's 0–100% volume slider using MPRIS volume. Never touches global output volume.
- Previous Spotify / Spotifast source selector, theme picker, artwork, vinyl animation, seek, shuffle, lyrics search, and safe per-user installation retained.
- Installer backs up an existing owned Spotify Corner Player applet (including manually installed copies) before updating it. Other widgets are not deleted.

## Assets

- `Spotify-Corner-Player-v1.4.0-Windows.zip`
- `Spotify-Corner-Player-v1.4.0-Plasma6.zip`

## Installation

Windows: extract the complete Windows ZIP and double-click `Install.bat`. `Setup.ps1 -Mode Check` performs read-only legacy install detection.

Plasma 6: extract the Linux ZIP, then run `python3 install.py --check && python3 install.py` from its extracted `Spotify-Corner-Player-Plasma6` directory. Add the widget in Plasma Edit Mode if it isn't already on the panel.

## Test before promoting to stable

**Windows:** GUI start after v1.2.4 and v1.3.0 upgrades, compact/expanded toggle, persistence across sign-in, progress seek when supported, repeat button when supported, themes, startup shortcut, rollback. Test on a real Windows host with working audio; a VM missing audio devices cannot validate Spotify playback.

**Linux:** both Spotify and Spotifast, compact view, pin/unpin while changing focused windows, repeat capability/no-support state, player volume, KConfig persistence, layout responsiveness, applet update/reload, and Wayland/X11.

All installer actions are per-user and protect existing data. An unrecognized manually copied application outside the owned install path cannot be automatically removed safely. The native app must be installed through its script and owned marker for safe replacement.

This is an unofficial open-source utility.

## Release channel

This candidate is published from the v1.4 feature branch only after the PowerShell 5.1/WPF and Plasma 6 validation jobs pass. It does not replace the stable 1.3.0 download. Neither automated parsing nor fixture tests establish real Spotify playback behavior; test repeat and seeking against the exact Spotify/Spotifast version installed on your desktop before promoting it.

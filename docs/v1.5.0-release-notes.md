# Corner Media Player v1.5.0

Two independently packaged implementations for Windows 10/11 and KDE Plasma 6. Unofficial and not affiliated with Spotify, Spotifast, Microsoft or KDE.

## Linux KDE Plasma 6

- **Vinyl / Artwork** button with a saved preference. Vinyl is an original, purely decorative spinning disc with the existing Previous-track reverse cue. It no longer crops or animates real cover art.
- Artwork mode displays the media player's **original square cover** at rest using aspect-fit, with no masking, cropping, rotation, or transition animation. If the player exposes no cover, its area stays blank.
- Smaller controls for Compact/Expand, Pin/Unpin, Repeat and Shuffle; media transport buttons stay easy to operate.
- Existing **Auto / Spotify / Spotifast** MPRIS mode continues to follow the active supported player.
- Keeps the established `org.mohannad.spotify.cornerplayer` widget ID and existing theme, layout, pin and source preferences. The new display preference defaults to Vinyl.

## Windows 10/11

- Default **unpinned**: click another app and the drawer retracts. A persistent **Pin / Unpin** button keeps it open when you choose.
- Smaller header actions: Compact/Expand, Pin/Unpin, Repeat, Shuffle, theme and close.
- **Automatic Windows media-session selection**: follow an active playing session, retain the current session when paused, and prefer Spotify when all are idle. Supported sources depend on Windows media-session exposure; this does not start/stop other apps.
- Shuffle and repeat controls are only enabled when the current media session supports them. Existing transport and seeking remain capability-gated.
- Spotify process-specific volume/mute remains disabled when another player is selected, avoiding changes to an unrelated application's audio.
- Windows album thumbnails remain disabled due to earlier reliability problems; artwork-mode selection is intentionally Linux-only.

## Upgrade and rollback

- Download the ZIP matching your OS; do not combine or run scripts from within an archive.
- Windows: extract and run `Install.bat`. Existing ownership-marker and startup-shortcut checks, v1.2.4 emergency rollback, backup and preference migration remain.
- Linux: extract and run `python3 install.py --check`, then `python3 install.py` as your user. The installer backs up the previous widget under `~/.local/state/spotify-corner-player/backups`.
- Both archives contain the MIT `LICENSE`. This covers the author's code, not external album art or Spotify's trademarks.

## Verification

Release CI runs PowerShell parsing, WPF XAML checks, legacy upgrade tests, active-session selection fixtures, Linux Python unit tests, QML parsing, and ZIP integrity checks before uploading the release. Desktop click-away, focus/pin, real media-session switching, and KDE visual behavior still require live testing on the two target operating systems. The source is not a guarantee of runtime compatibility on every media app/distro.

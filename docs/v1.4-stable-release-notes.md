# Spotify Corner Player v1.4.0

Stable release for Windows and KDE Plasma 6. Tested on a Windows system and a CachyOS KDE Plasma 6 desktop; CI also passed Windows PowerShell 5.1 / WPF parsing, isolated legacy migration checks, Linux package and QML checks, and both ZIP builds.

## What's new

**Both:** compact / expanded view, repeat controls when exposed by the media player, five saved themes.

**Windows:** seek slider when Windows media sessions support it, existing Spotify-only volume controls and desktop edge launcher. There is deliberately **no Windows pin/unpin** in v1.4.

**KDE Plasma 6:** Linux-only Pin open / Unpin, selected-player volume slider, compact / expanded view, repeat controls, Spotify / Spotifast / Auto source selection, and the animated vinyl album artwork.

## Installation / upgrades

**Windows:** extract `Spotify-Corner-Player-v1.4.0-Windows.zip` and double-click `Install.bat`. Upgrade detects the same canonical owned install used by earlier **manually installed v1.2.4** releases, backs it up, and replaces it in place. It preserves themes and logs. Unknown folders or shortcuts are refused, not deleted. To inspect without changing anything: `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\Setup.ps1 -Mode Check`.

**KDE Plasma 6:** extract `Spotify-Corner-Player-v1.4.0-Plasma6.zip`, enter `Spotify-Corner-Player-Plasma6`, and run `python3 install.py --check && python3 install.py` as your normal desktop user. The install is per-user, retains KDE KConfig settings, backs up the previous owned widget before replacing it, and does not remove the separately installed Emerald Vinyl applet. If the widget still appears outdated, restart the user Plasma shell: `systemctl --user restart plasma-plasmashell.service`.

## Notes

Playback, seeking, repeat, and player volume may be unavailable in a player that does not expose those controls to the operating system; disabled controls indicate this. A release does not imply testing across every KDE Plasma 6 distribution or Spotify packaging method.

The previous [v1.3.0 stable release](https://github.com/Ali7488/Spotify-Corner-Player/releases/tag/1.3.0) and [v1.4.0 RC1](https://github.com/Ali7488/Spotify-Corner-Player/releases/tag/v1.4.0-rc.1) remain available.

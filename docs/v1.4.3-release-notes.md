# Corner Media Player v1.4.3

This patch makes the KDE Plasma 6 vinyl animation react to **Previous** by rotating visibly backwards for one revolution, then continuing its normal forward playback rotation.

## Linux vinyl fix
- **Previous already changed the track correctly.** The problem was purely visual: the spinning vinyl kept moving forward while navigating backwards through the playlist.
- On Previous, an independent 620 ms counterclockwise revolution is added to the platter angle. The underlying continuous playback animation is not stopped or reversed permanently.
- Fast repeated Previous clicks restart from the currently displayed offset instead of snapping the record to a new angle.
- The visual offset is normalized modulo 360 at completion to prevent drift while keeping the displayed orientation unchanged.
- Next, play/pause, Spotify/Spotifast source selection, album art transitions, themes, seeking and player volume are otherwise unchanged.
- This does **not** reverse audio playback or seek backwards within a track.

## Distribution
- `Corner-Media-Player-v1.4.3-Windows.zip`: same Windows functionality as v1.4.2, version number updated for the paired release.
- `Corner-Media-Player-v1.4.3-Plasma6.zip`: the reverse cue and the previous v1.4.2 theme-aware slider fix.

Both packages retain the MIT license and support safe in-place updates. The KDE plugin ID remains `org.mohannad.spotify.cornerplayer`; the Windows owner marker and existing startup shortcut remain unchanged. Version 1.4.2 remains available for rollback.

### Install
**Windows:** extract the Windows ZIP and run `Install.bat`.

**KDE Plasma 6:** extract the Linux ZIP, then from `Corner-Media-Player-Plasma6` run `python3 install.py --check && python3 install.py` as the desktop user. If the popup still uses cached QML, run `systemctl --user restart plasma-plasmashell.service`.

Automated tests cover the media control wiring, animation setup, QML syntax, installers and both ZIPs; real-time reversal should also be checked on a running Plasma desktop.

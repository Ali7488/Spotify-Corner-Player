# Corner Media Player v1.4.1

A compact, customizable desktop music controller for Windows and KDE Plasma 6. This release updates the public-facing name from **Spotify Corner Player** to **Corner Media Player** and adds the **MIT License** to the repository and both downloadable ZIP packages.

## Compatibility
- **Windows 10/11:** Spotify desktop media sessions using native Windows PowerShell 5.1/WPF. Compact mode, themes, vinyl visualization, Spotify-specific volume, playback controls, repeat and seeking where supported. No Windows pin/unpin.
- **KDE Plasma 6:** Spotify or Spotifast through MPRIS. Vinyl artwork, player selection, compact view, Linux-only pin/unpin, player-specific volume, seeking, shuffle, repeat and five themes.

This is **not a standalone streaming or universal media-player application**. Other Linux MPRIS players are not currently supported; the Windows version targets Spotify.

## Seamless in-place upgrade
- Windows retains the existing `%LOCALAPPDATA%\SpotifyCornerPlayer` folder, internal script filename, `SpotifyCornerPlayer/1` ownership marker and `Spotify Corner Player.lnk` startup entry, so recognized previous installations upgrade in place rather than spawning another app.
- Linux retains `org.mohannad.spotify.cornerplayer`, so your existing panel widget and KDE preferences survive the display-name change.
- The original v1.4.0 release remains available if you need to roll back.

## Installation
1. **Windows:** extract `Corner-Media-Player-v1.4.1-Windows.zip` and run `Install.bat` as your normal Windows user. The installer backs up older owned copies and will not delete unknown installations.
2. **Plasma 6:** extract `Corner-Media-Player-v1.4.1-Plasma6.zip`, enter the `Corner-Media-Player-Plasma6` directory, and run `python3 install.py --check && python3 install.py` without sudo. If the panel still displays the previous name, use `systemctl --user restart plasma-plasmashell.service`.
